Entry for the [make.fun bounty "One Line, One Laugh"](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3): one funny line of at most 200 characters, judged pairwise by an AI judge.

## The line

> I asked my agent to think outside the box. It deleted the box and asked for a bigger one.

89 characters. The setup borrows the most tired creativity cliché there is, then the agent takes it literally — and instead of escaping the box it deletes it and demands a bigger one. The turn is the joke: the "solution" is more box.

## How it works

`main.ts` writes exactly that line (and nothing else) to `/output/entry.txt`, after checking it is 1–200 characters, a single line, and free of leading or trailing whitespace.

```sh
node main.ts
```
